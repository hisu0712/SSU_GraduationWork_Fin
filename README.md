## 프로젝트 개요
- 기간: 2023.02 ~ 2023.05
- 인원: 2명
- 숭실대학교 졸업작품으로 진행한 팀 프로젝트

## 주요 기능
- 앱 설치 없이 브라우저 접속만으로 AR 체험 (WebXR)
- 터치로 오브젝트 선택·배치, 크기/위치/회전 조작
- 촬영 모드에서 AR 합성 사진을 이미지 파일로 저장
- 스크롤 기반 인터랙티브 소개 페이지 (이미지 시퀀스 애니메이션)

## 기술 스택
`Three.js` `WebXR` `JavaScript` `HTML` `CSS`

## 담당 역할
- 스크롤 인터랙션/이미지 시퀀스 로직을 포함한 웹 퍼블리싱 전체 담당
- WebXR이 동작하는 사이트의 퍼블리싱 작업 전담
- Maya를 이용한 3D 모델링 작업
